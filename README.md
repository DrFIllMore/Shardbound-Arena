# Shardbound Arena

A single-file Three.js action RPG built for phones in landscape.

**Play:** https://drfillmore.github.io/Shardbound-Arena/

- On iPhone: open the link in Safari → Share → **Add to Home Screen**. Launched from the home-screen icon it runs full screen with no browser bars.
- The game always plays in landscape; with rotation lock on, it turns itself — hold the phone with its top to the left.
- Progress is saved on the device (browser storage). It is separate from progress made in the Claude artifact version.

`index.html` is the whole game; Three.js r128 loads from jsDelivr.
